## 2. PDO, TRANSACTIONS, LOCKING

### PHPX-6
Исправь SQL injection и некорректную типизацию:

```php
$id = $_GET['id'];
$user = $pdo->query("SELECT * FROM users WHERE id = $id")->fetch();
```

Нужно отличать invalid id от user not found.

### PHPX-7
Два процесса одновременно выполняют «прочитать balance; проверить >=100; записать balance-100». Покажи race condition и два корректных решения PostgreSQL: `SELECT ... FOR UPDATE` и атомарный `UPDATE ... WHERE balance >= ... RETURNING`.

### PHPX-8
Напиши функцию `runTransactionWithDeadlockRetry(PDO $pdo, callable $fn, int $maxAttempts = 3)`:
- повторять только deadlock/serialization failure;
- rollback при ошибке;
- exponential backoff с jitter;
- прочие исключения сразу пробрасывать;
- не скрывать исходную ошибку после последней попытки.

### PHPX-9
Почему нельзя держать SQL-транзакцию открытой во время 6-секундного payment HTTP? Дай устойчивый flow с pending-state, idempotency и reconciliation.

### PHPX-10
Transactional outbox: дай PostgreSQL schema и PHP flow записи заказа + события в одной транзакции. Затем опиши worker publication с `FOR UPDATE SKIP LOCKED` и защитой от дублей.
